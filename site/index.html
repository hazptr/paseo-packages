Paseo package repository

Unofficial APT and DNF repositories for the Paseo desktop releases (x86_64). Packages download straight from the upstream release; only the signed indexes live here. Current versions: @VERSIONS@.

Fedora / RHEL / openSUSE (dnf, zypper)

sudo curl -fsSLo /etc/yum.repos.d/paseo.repo @PAGES_URL@/paseo.repo
sudo dnf install Paseo

zypper: sudo zypper addrepo @PAGES_URL@/paseo.repo && sudo zypper install Paseo

Debian / Ubuntu (apt)

sudo install -d /etc/apt/keyrings
sudo curl -fsSLo /etc/apt/keyrings/paseo.gpg @PAGES_URL@/paseo.gpg
sudo curl -fsSLo /etc/apt/sources.list.d/paseo.list @PAGES_URL@/paseo.list
sudo apt update && sudo apt install paseo

Turn off Paseo's own updater

Paseo has no setting for this: it downloads new versions itself and installs them on quit. Its updater only runs on deb/rpm installs when /opt/Paseo/resources/package-type exists, so tell rpm or dpkg never to install that file, then delete the copy already there. The rule survives upgrades.

# Fedora / RHEL / openSUSE
echo '%_netsharedpath /opt/Paseo/resources/package-type' | sudo tee /etc/rpm/macros.paseo-no-updater

# Debian / Ubuntu
echo 'path-exclude=/opt/Paseo/resources/package-type' | sudo tee /etc/dpkg/dpkg.cfg.d/paseo-no-updater

# both
sudo rm -f /opt/Paseo/resources/package-type
